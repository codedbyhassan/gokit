# Code of Conduct

## Our commitment

GoKit is a technical project intended to be welcoming to contributors with different backgrounds and levels of experience. Participants are expected to communicate professionally and treat one another with respect.

## Expected behavior

- Be respectful and constructive.
- Focus criticism on code, decisions, and technical trade-offs rather than people.
- Assume good intent while remaining precise about technical concerns.
- Welcome different perspectives and reasonable disagreement.
- Give actionable feedback when reviewing contributions.

## Unacceptable behavior

Harassment, discrimination, personal attacks, intimidation, threats, deliberate disruption, and publishing private information without permission are not acceptable.

## Enforcement

Project maintainers may remove comments, close discussions, reject contributions, or restrict participation when behavior violates this code of conduct.

## Reporting

Report serious conduct concerns privately to the project maintainer rather than through a public issue. Security vulnerabilities should be reported according to [SECURITY.md](SECURITY.md).

## Scope

This code applies to project repositories, issues, pull requests, discussions, and other project spaces where contributors represent or participate in GoKit.
